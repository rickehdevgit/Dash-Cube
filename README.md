# Dash-Cube
Dash Cube é um jogo de obstáculos onde você controla um cubo amarelo e precisa pular para evitar colisões. Desvie de espinhos e blocos, teste seus reflexos e tente alcançar a maior distância possível! Supere seu recorde a cada tentativa neste jogo de navegador com obstáculos aleatórios e cores dinâmicas.
